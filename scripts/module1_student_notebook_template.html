Spoken Technical English Principles (The 70/30 Rule) Classroom Contract

1. Active Talk-Time: Spend ≥70% of each 2-hour session in active speaking (pairs, simulations, debates), not passive reading.

2. Modal Precision: Never confuse shall (mandatory) with should (recommendation) in regulatory speech.

3. Spontaneous Delivery: Deliver all presentations from bulleted slide prompts. Strictly zero reading from pre-written scripts!

4. Active Listening: Challenge peer findings constructively during Q&A using professional, evidence-backed arguments.

EASA CAP Validation CriteriaContainment vs Preventative
Immediate Containment (Within 24–48 hours): Stops the hazard immediately (e.g., temporary NOTAM, stand closure, extra spotters).
Long-Term Preventative Action (30–90 days): Fixes the root cause (e.g., software patch, procedure revision, physical redesign).
